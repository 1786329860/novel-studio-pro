# Novel Studio Pro 前端 v0.3.0 给 Trae 的开发说明

这是一个 Windows 桌面软件前端项目，目标是后续打包成 EXE。当前版本是 Electron + 原生 HTML/CSS/JS，不需要登录，不需要浏览器，不需要 React。

## 这版已经包含的页面

只使用这个代码包，不要再混用旧 UI 包。

- 项目总览
- 新建项目
- 故事蓝图
- 角色系统
- 伏笔与真相
- 章节写作
- 状态面板
- 事件账本
- 全局记忆
- 生成设置
- 模型配置
- DeepSeek API 设置

## 第一步：运行前端

进入项目目录：

```bash
cd novel-studio-pro-frontend-v3
```

安装依赖：

```bash
npm install
```

启动：

```bash
npm run dev
```

如果窗口正常打开，说明前端成功。

## 第二步：测试完整 Mock 流程

先不要接 DeepSeek，先测试 UI 和流程。

1. 打开软件。
2. 进入“新建项目”。
3. 输入小说名和总大纲。
4. 点击“开始自动构建小说”。
5. 查看“故事蓝图”。
6. 依次查看“角色系统”“伏笔与真相”“全局记忆”“生成设置”“模型配置”“DeepSeek API 设置”。
7. 进入“章节写作”。
8. 点击“生成下一章”。
9. 点击“确认本章入库”。
10. 进入“状态面板”和“事件账本”，确认数据变化。

## 不要做的事情

请 Trae 严格遵守：

1. 不要做登录注册。
2. 不要把 DeepSeek API Key 写死到代码里。
3. 不要让前端直接请求 DeepSeek 官方接口。
4. 不要删除 Mock 模式。
5. 不要删除“生成下一章”和“确认本章入库”两步。
6. 不要把项目改成普通网页项目。
7. 不要擅自重构成 React 或 Vue，当前先保持 Electron + 原生 JS。
8. 不要把浅色青春活力 UI 改回暗黑风。

## 后端接入原则

当前前端调用 `src/api.js`。Mock 模式开启时调用 `src/mock.js`。Mock 模式关闭时调用本地后端：

```text
http://127.0.0.1:8765
```

后续做后端时，只需要实现 `API_CONTRACT.md` 里的接口。

## UI 文件说明

- `src/renderer.js`：所有页面渲染和点击逻辑。
- `src/styles.css`：所有 UI 样式，青春活力浅色主题在这里。
- `src/store.js`：本地状态和设置，使用 localStorage。
- `src/mock.js`：模拟后端数据，方便没有后端时演示。
- `src/api.js`：前端 API 统一入口，未来对接 FastAPI 后端。
